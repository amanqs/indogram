Telegram MTProto API Framework
Elegan, Asinkron & Bertenaga

Bangun bot Telegram dan otomatisasi akun (userbot) berkecepatan tinggi dengan Python. 100% kompatibel sebagai drop-in replacement untuk pyrogram dan dilengkapi helper khas pengembang Indonesia.

$ pip install indogram
Mulai Sekarang → Eksplorasi API

Mengapa Memilih Indogram?

Dibangun di atas fondasi kuat MTProto dengan fitur modern dan kemudahan maksimal.

🔄

Dual-Import Compatibility

Gunakan import indogram untuk proyek baru, atau tetap gunakan import pyrogram untuk bot yang sudah ada tanpa perlu mengubah kode lama.

⚡

Asinkron & Kecepatan Tinggi

Ditenagai oleh arsitektur asyncio, dengan opsi akselerasi C melalui TgCrypto dan uvloop untuk throughput pesan maksimal.

🇮🇩

Utilitas Khas Indonesia

Helper bawaan untuk zona waktu (WIB, WITA, WIT), formatting mata uang Rupiah (format_rupiah), dan format tanggal Indonesia.

📱

Fitur MTProto Terbaru

Mendukung fitur-fitur Telegram terkini: Stories, Forum Topics, Business Accounts, Star Gifts, Reactions, dan Channel Direct.

🛡️

Type-Hinted & PEP 561

Mendukung auto-completion cerdas di Visual Studio Code, Cursor, PyCharm, dan Antigravity IDE dengan anotasi tipe lengkap.

🤖

Dual Mode: Bot & Userbot

Satu library untuk segalanya: bot resmi via Bot Token (@BotFather) atau client kustom langsung menggunakan akun pengguna Telegram.

Panduan 3 Langkah Memulai

Dari nol hingga bot pertama Anda online dalam waktu kurang dari 5 menit.

1

Dapatkan Kredensial Telegram

Kunjungi my.telegram.org untuk membuat aplikasi dan mendapatkan API_ID serta API_HASH. Buat bot token di @BotFather.

2

Install Library Indogram

Buka terminal dan install paket resmi dari PyPI:

pip install indogram
3

Tulis & Jalankan Kode

Simpan kode ke file bot.py lalu jalankan dengan python bot.py.

Contoh Kode Siap Pakai

Pilih contoh skenario di bawah ini untuk melihat implementasi nyatanya.

echo_bot.py 
from indogram import Client, filters
from indogram.types import Message

# Ganti dengan kredensial Anda dari my.telegram.org & @BotFather
app = Client(
    "echo_bot",
    api_id=1234567,
    api_hash="your_api_hash_here",
    bot_token="your_bot_token_here",
)

@app.on_message(filters.command("start"))
async def start_handler(client: Client, message: Message):
    await message.reply_text(
        f"👋 Halo **{message.from_user.first_name}**!\n"
        "Selamat datang di bot bertenaga **Indogram**!"
    )

@app.on_message(filters.text & filters.private)
async def echo_handler(client: Client, message: Message):
    await message.reply_text(f"Anda berkata: {message.text}")

if __name__ == "__main__":
    print("Bot Indogram sedang berjalan...")
    app.run()
button_bot.py 
from indogram import Client, filters
from indogram.types import InlineKeyboardMarkup, InlineKeyboardButton, CallbackQuery, Message
from indogram.utils import format_rupiah

app = Client("button_bot", api_id=1234567, api_hash="HASH", bot_token="TOKEN")

@app.on_message(filters.command("menu"))
async def menu_handler(client: Client, message: Message):
    keyboard = InlineKeyboardMarkup([
        [
            InlineKeyboardButton("🛒 Cek Harga", callback_data="check_price"),
            InlineKeyboardButton("ℹ️ Info", callback_data="info")
        ],
        [
            InlineKeyboardButton("🌐 Repository", url="https://github.com/amanqs/indogram")
        ]
    ])
    await message.reply_text("Silakan pilih menu:", reply_markup=keyboard)

@app.on_callback_query()
async def callback_handler(client: Client, query: CallbackQuery):
    if query.data == "check_price":
        # Gunakan utilitas format_rupiah bawaan Indogram
        harga = format_rupiah(50000)
        await query.answer(f"Harga langganan: {harga}", show_alert=True)
    elif query.data == "info":
        await query.answer()
        await query.message.edit_text("Indogram adalah framework Telegram MTProto modern.")

app.run()
userbot.py 
import asyncio
from indogram import Client, filters
from indogram.types import Message
from indogram.utils import format_date_id, now_wib

# Login akun pengguna Telegram biasa (Userbot)
app = Client("my_account", api_id=1234567, api_hash="your_api_hash")

@app.on_message(filters.me & filters.command("ping", prefixes="."))
async def ping(client: Client, message: Message):
    waktu = format_date_id(now_wib())
    await message.edit_text(f"🏓 **Pong!**\nServer: `{waktu}`")

async def main():
    async with app:
        me = await app.get_me()
        print(f"Userbot aktif sebagai: {me.first_name} (@{me.username})")
        await asyncio.Event().wait()

if __name__ == "__main__":
    asyncio.run(main())
indonesian_helpers.py 
from indogram.utils import (
    WIB, WITA, WIT,
    now_wib,
    format_rupiah,
    format_bytes,
    format_date_id
)

# 1. Format Mata Uang Rupiah
print(format_rupiah(1500000))
# Output: 'Rp 1.500.000'

# 2. Waktu Saat Ini Zona WIB (UTC+7)
print(now_wib())
# Output: 2026-09-24 23:55:00.123456+07:00

# 3. Format Tanggal Bahasa Indonesia
print(format_date_id())
# Output: 'Kamis, 24 September 2026, 23:55 WIB'

# 4. Format Ukuran File/Memory
print(format_bytes(52428800))
# Output: '50.00 MB'

Eksplorasi Referensi API

Koleksi method, filter, dan utilitas yang sering digunakan di Indogram.

Client

Client.send_message(chat_id, text, ...)

Mengirim pesan teks ke pengguna, grup, atau channel Telegram.

await app.send_message("chat_id", "Halo Dunia!")
Client

Client.send_photo(chat_id, photo, caption, ...)

Mengirim gambar/foto dengan caption dan parse mode Markdown atau HTML.

await app.send_photo("chat_id", "gambar.jpg", caption="Lihat ini!")
Client

Client.get_me()

Mengambil informasi akun atau bot yang saat ini sedang aktif (User object).

me = await app.get_me()
Filters

filters.command(commands, prefixes)

Memfilter pesan yang diawali tanda perintah (default /, contoh: filters.command("start")).

@app.on_message(filters.command(["start", "help"]))
Filters

filters.text & filters.private

Kombinasi operator logika (AND &, OR |, NOT ~) untuk menyaring pesan.

@app.on_message(filters.text & ~filters.bot)
Types

Message.reply_text(text, ...)

Membalas pesan yang masuk secara langsung tanpa perlu mengetikkan ID chat.

await message.reply_text("Dibalas otomatis!")
Utilitas ID

format_rupiah(amount, prefix="Rp ")

Memformat angka desimal/integer menjadi format standar mata uang Rupiah Indonesia.

format_rupiah(75000) # -> 'Rp 75.000'
Utilitas ID

format_date_id(dt=None, include_time=True)

Format tanggal dan waktu otomatis dalam bahasa Indonesia dengan penanda zona waktu.

format_date_id() # -> 'Kamis, 24 September 2026, 23:55 WIB'
Utilitas ID

WIB, WITA, WIT / now_wib()

Objek zona waktu bawaan (UTC+7, UTC+8, UTC+9) untuk kemudahan penanganan jam server.

now = now_wib() # Datetime dengan timezone WIB
